# Rules for NBC tactic decks (PMR and every weekly tactic)

These apply every time a tactic deck is built or updated.

1. **Link to the exact GitHub file on every slide.** Each slide footer carries "GitHub:" links to the specific files in this repo that back the slide (for example `marketing/INTERVIEW_SCRIPT.md`, not just the repo root). The title slide links to the repo and the tactic's folder, and the last slide lists every source file. The deck build fails if a slide has no file link.
2. **Follow the course template, and don't compress slides.** Use the Startup Tactics template's sections, prompts and order, styled in the NBC brand (`brand/BRAND.md`: Unbounded titles, NBC colours, NBC lockup). Keep the elevator pitch exactly as written in the thesis; add slides within a section rather than shrinking text. Keep body text at readable sizes (about 24px or more on the 1920×1080 canvas). When content doesn't fit, split it across duplicated slides ("1 of 3", "2 of 3"…) instead of shrinking the type or cutting content.
3. **Use plain language.** Say "programme owners: the people who run after-school clubs, holiday camps and learning centres", not "operators". Avoid jargon.
4. **Be honest about status.** Mark work as Sourced, Scheduled or Rehearsal (simulated). Never date an unsent message or an interview that hasn't happened in the past, and never present simulated results as evidence.
5. **Weeks run Wednesday to Tuesday.** Tactic decks are due on Tuesdays.
6. **Link the live CRM.** Outreach, interview and findings slides link to the [PMR CRM on Google Sheets](https://docs.google.com/spreadsheets/d/11LfHholpkKC0vhpQ7z_DvRme57lPln2jZR7Nm4EMrjg/edit), alongside the GitHub files. The CRM is built by `marketing/crm/NBC_CRM.gs` (combined from `marketing/crm/src/`); keep the deck, guide and script in step, and run `node marketing/crm/tests/acceptance.test.js` before publishing a change. Email delivery must stay off until an Admin confirms recipients, and no automated message may go to external contacts.
7. **Publish in `weekly-tactics/NN-name/`** as a PDF (to upload) with clickable links, a PPTX with link hotspots, and a PNG per slide. Don't use the word "assignment" in names.
8. **This repo is public: keep private material out.** Never add invention or prototype mechanisms (how devices, sensing, capture or evidence syncing work), patent notes, demo videos, real people's names or contact details, interview notes or screenshots, anything about children, detailed financials or credentials. Describe inventions at vision level only. That material lives in the team's private repo. Keep the CRM Sheet's sharing restricted; never set it to "anyone with the link".
9. **Global brand, local proof.** The brand never reads as Ghana-only. Keep countries out of the logo, master line, taglines and signatures. Frame Ghana as where we start ("starting in Cape Coast, Ghana"); go-to-market material can be local. See [brand/BRAND.md](brand/BRAND.md#scope-global-brand-local-proof).
