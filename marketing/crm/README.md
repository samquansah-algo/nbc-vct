# PMR CRM

**Live CRM (Google Sheets): [NBC PMR CRM (Fall 2026)](https://docs.google.com/spreadsheets/d/11LfHholpkKC0vhpQ7z_DvRme57lPln2jZR7Nm4EMrjg/edit)**

This is where we track every outreach message, reply, follow-up and interview for the market research tactic. The dashboard updates itself.

## What's in the live sheet

| Section | What it does |
|---|---|
| **Dashboard** | Messages planned, sent, replies, reply rate, follow-ups due now, interviews booked; interviews scheduled and done against the target of 10; v1 against v2 reply rates; problems confirmed |
| **Outreach pipeline** | All 22 planned touches (10 v1 messages, 2 Cape Coast canvassing days, 10 v2 messages including the R6 follow-up), each linked to its exact message on GitHub. **Stage** fills in by itself: Scheduled → Sent → Follow up (no reply after 5 days) → Replied → Booked. **Days to reply** and **Follow-up due** are calculated |
| **Interviews** | The 10 scheduled interviews with target dates, status, consent, notes fields, and problem ratings P1–P5 (0–3) |
| **Insights grid summary** | For each problem: how many were rated, how many rated 2+, how many buyers rated 2+, and whether the problem is **Confirmed** (6+ of 10, including 3+ buyers) |

## How to use it
1. When you send a message, type the **Sent date** and paste a **screenshot link**.
2. When someone replies, type the **Reply date**. Set **Booked?** to Yes when an interview is agreed, or use **Outcome** (for example Declined).
3. After each interview, set **Status** to Done, fill in the notes the same day and rate P1–P5.
4. Don't type in the "(auto)" cells.

## Privacy
The live sheet is linked from this public repository. **Log people by role only** (Owner 1, Facilitator 2…). Keep names, emails and phone numbers in your own private address book, and never record children. Only set the sheet's sharing to "Anyone with the link can view" while it holds no personal details; otherwise keep it restricted to the team.
