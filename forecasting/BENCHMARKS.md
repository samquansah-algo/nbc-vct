# Benchmarks

*How we compare NBC with organisations that built similar layers, and with the numbers we measure ourselves against. Figures are cited in the linked documents.*

## Who built layers like this

| Benchmark | What it proves | Lesson for NBC |
|---|---|---|
| International Baccalaureate | A trusted network without owning schools | Trust takes years, so start now |
| Red Hat and Linux | An open standard plus a commercial company | Open format; paid services |
| UL Solutions | Certification can be a large, listed company | Use independent assessors |
| LEED | A voluntary standard reshaped an industry | Certify worlds first, then centres |
| ImageNet, ARC Prize | Benchmarks shape what AI labs build | Physical-reasoning tests, with paid adults only |
| 2U, Byju's | Debt-led expansion can sink edtech | Gate every spend on evidence |
